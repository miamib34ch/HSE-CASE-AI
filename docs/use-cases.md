# Основные use cases

1. Пользователь создаёт проект и загружает требования.
2. Аналитик требований формирует структуру.
3. Пользователь подтверждает структуру.
4. Генератор кода создаёт backend/frontend/infra/documentation артефакты.
5. Инженер по тестированию создаёт тестовые артефакты и результаты.
6. Инженер деплоя выполняет dry-run deployment.
7. Оператор подключает MCP server и просматривает capabilities.
8. Внешний AI-client вызывает MCP surface платформы.
