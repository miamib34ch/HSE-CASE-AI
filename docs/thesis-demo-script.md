# Сценарий демонстрации

1. Показать `docker compose up --build` и открыть UI.
2. Создать проект на дашборде.
3. Открыть проект и вставить `examples/demo_requirements.md`.
4. Запустить структурирование требований.
5. Показать JSON и Markdown структуру.
6. Подтвердить структуру как human-in-the-loop шаг.
7. Запустить генерацию кода.
8. Показать созданные артефакты и историю запусков.
9. Запустить генерацию тестов.
10. Показать test results, coverage summary и junit artifact.
11. Запустить dry-run deploy.
12. Перейти на экран `MCP`, показать встроенные demo servers, tools/resources/prompts и вызов `list_projects`.
13. Перейти на экран `Агенты`, запустить одного агента по project id и показать журнал выполнения.
14. При наличии ключей показать provider validation и fallback.
