# Ограничения MVP

- Реальные вызовы внешних LLM API оформлены слоем адаптеров, но по умолчанию используются demo-ответы.
- Alembic-миграции представлены стартовой миграцией; для production нужен полный autogenerate cycle по всем таблицам.
- Remote MCP transport реализован как минимальный безопасный слой, а не как полнофункциональный streaming client.
- Python MCP SDK подключается как optional dependency, так как в части окружений пакет может быть недоступен через индекс пакетов.
- Реальный deploy зависит от локального Docker и в MVP ограничен проверкой manifest.
- Авторизация пользователей представлена доменной моделью, но не включена в UI/API как завершённый auth-модуль.
