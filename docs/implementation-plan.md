# План реализации MVP

## Цель
Собрать локально разворачиваемую CASE-платформу с demo mode, веб-интерфейсом, backend API, слоем LLM-провайдеров, MCP client/server, агентной оркестрацией и файловым хранилищем артефактов.

## Этапы
1. Подготовить монорепозиторий, конфигурацию окружения, Docker Compose, базовые инструменты качества и структуру документации.
2. Реализовать backend foundation: настройки, логирование, middleware, SQLAlchemy-модели, сессии БД, миграции, healthcheck и storage layer.
3. Реализовать реестр LLM-провайдеров с общим интерфейсом, demo adapter и безопасными HTTP-адаптерами для OpenAI, Anthropic, GigaChat, YandexGPT и OpenRouter.
4. Реализовать CASE workflow: загрузка требований, анализ и структурирование, подтверждение структуры, генерация артефактов кода, генерация тестов и dry-run deployment.
5. Реализовать MCP integration layer: registry серверов, встроенные demo MCP servers, вызовы tools/resources/prompts, журналирование и политики trust level.
6. Реализовать agent orchestration layer с профилями агентов, handoff, памятью, approval flow и связью с проектами.
7. Реализовать frontend на React/Vite с экранами управления проектами, pipeline, провайдерами, MCP, агентами, логами и артефактами.
8. Добавить тесты, CI, pre-commit, расширенную документацию и демонстрационный сценарий.
9. Выполнить локальную проверку, устранить ошибки запуска и зафиксировать команды демонстрации.

## MVP-решения
- По умолчанию система работает в `demo mode` через `FakeLLMAdapter`.
- Генерация кода и тестов создаёт детерминированные артефакты-шаблоны, пригодные для просмотра, скачивания и локального dry-run deploy.
- Реальный deploy поддерживается через вызов `docker compose`, но для защиты основным сценарием считается безопасный dry-run.
- MCP SDK используется опционально: при наличии пакета платформа поднимает MCP server, без него не падает и сохраняет HTTP API.
